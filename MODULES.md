# Модули — что есть и для чего

> 💡 **Главная идея:** core (база) ставится **без единого ключа**, модули добавляете когда захотите. Хотите Claude+правила — поставьте core. Захотели Telegram через неделю — поставите модуль. Через месяц захотели бэкап — поставите ещё один. Никаких «вы должны указать все ключи сразу».

---

## Как ставить любой модуль

```bash
sudo bash install.sh --module ИМЯ_МОДУЛЯ
```

Список модулей внутри:
```bash
bash install.sh --list
```

Удалить модуль:
```bash
sudo bash uninstall.sh --module ИМЯ_МОДУЛЯ
```

## 📱 tg-bot — Telegram-бот для Claude

**Что даёт:** управлять Claude из Telegram прямо с телефона. Написал «сделай мне отчёт по продажам» — Claude получил, поработал, прислал ответ. Можно отправлять текст, голос, фото, файлы.

**Когда нужно:** если вы часто думаете о работе вне рабочего места и хотите чтобы Claude всегда был под рукой как обычный собеседник в TG.

**Что вам нужно подготовить:**
1. **Telegram-бот** — создаётся бесплатно за минуту:
   - Откройте в TG чат с [@BotFather](https://t.me/BotFather)
   - Напишите `/newbot`, придумайте имя
   - Получите токен вида `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`
2. **Telegram-группа** — создайте обычную группу (или используйте существующую):
   - Добавьте туда вашего бота
   - Узнайте `chat_id` группы (бот сам напечатает в логах при первом сообщении)

**Что произойдёт при установке:**
- Скрипт скопирует код бота в `/opt/claude-telegram-router/`
- Создаст systemd-сервис `tg-router.service` с `Restart=always` и **enabled** (после перезагрузки сервера сам запустится)
- Спросит токен бота интерактивно (или возьмёт из `.env`)
- Опционально настроит «топики» внутри группы (форум-режим) для разделения проектов

**Если нужен второй бот** (для семьи/команды/тестового канала):
```bash
sudo bash install.sh --module tg-bot -- --second-bot
```
Поставит независимый `tg-router2.service` со своим токеном и runtime-директориями.

**Подробная инструкция:** [TELEGRAM-SETUP.md](docs/TELEGRAM-SETUP.md)

**Установка:**
```bash
sudo bash install.sh --module tg-bot
```

## 💾 backup — Автоматические бэкапы на Яндекс.Диск

**Что даёт:** каждую ночь весь ваш сервер (важные файлы, базы данных, конфиги) копируется на Яндекс.Диск с шифрованием. Если сервер сгорит или его арестуют — у вас всё на руках. 17 точек восстановления до 6 месяцев в прошлое.

**Когда нужно:** **всегда.** Это базовая защита. Сервера ломаются, провайдеры банят аккаунты, на хостинг полиция приходит — это реально случается. Бэкап стоит копейки, спасает всё.

**Что вам нужно подготовить:**
1. **Яндекс.Диск** — у вас уже есть, скорее всего. Если нет — [бесплатно 5 ГБ](https://disk.yandex.ru/) (хватает на маленький сервер).
2. **OAuth-приложение в Яндексе** — создаётся за 2 минуты, нужно один раз:
   - Откройте https://oauth.yandex.com/client/new
   - Имя: `server-backup-restic`
   - Платформа: «Веб-сервисы», Redirect URI: `https://oauth.yandex.ru/verification_code`
   - Разрешения: «Яндекс Диск REST API» → отметить read/write/info
   - Получите ClientID и Client secret

**Что произойдёт при установке:**
- Установится `restic` (для шифрованных бэкапов) и `rclone` (для общения с Яндекс.Диском)
- Скрипт интерактивно проведёт через OAuth (откроете ссылку, скопируете код)
- Сгенерируется restic-пароль (44 случайных символа) — **обязательно сохраните в Bitwarden + распечатайте на бумаге**
- Создастся ежедневный cron на 03:00
- Первый тестовый бэкап (5-15 минут на ~2-3 ГБ)
- TG-уведомления о статусе (если установлен модуль `tg-bot`)

**Подробная инструкция:** [BACKUP-SETUP.md](docs/BACKUP-SETUP.md)

**Установка:**
```bash
sudo bash install.sh --module backup
```

## 🎙️ parakeet — Транскрипция голосовых сообщений

**Что даёт:** Claude понимает ваши голосовые сообщения. Особенно полезно в связке с tg-bot: отправили голосовое в TG — бот скачал, расшифровал, отдал Claude как текст. Можно надиктовать длинную задачу за минуту вместо того чтобы печатать пять.

**Когда нужно:** если вы голосовой человек (или ездите за рулём и хотите давать Claude поручения).

**Что вам нужно подготовить:**
1. **HuggingFace аккаунт** — бесплатно: https://huggingface.co/join
2. **HuggingFace токен** — Settings → Access Tokens → New token (тип read). Нужен только для скачивания модели один раз.

**Что произойдёт при установке:**
- Скачается модель Parakeet-TDT 0.6B v3 (~600 МБ) — это open-source модель от NVIDIA, работает локально
- Установится HTTP-сервис на порту 8089
- Создастся systemd-юнит для автозапуска
- Если установлен tg-bot — автоматически подключится к нему

**Альтернатива:** GigaAM v3 от Сбера (русский язык лучше). Можете поставить вместо Parakeet через `--variant gigaam`.

**Установка:**
```bash
sudo bash install.sh --module parakeet
# или
sudo bash install.sh --module parakeet --variant gigaam
```

## 🧠 Память — context-mgr + Obsidian-vault (не отдельный модуль)

**Раньше** была кросс-сессионная память через плагин claude-mem. В текущей версии **claude-mem убран** — память реализована через `context-mgr` + Obsidian-vault и ставится автоматически при provision-user (V2).

**Что даёт:** когда сессия разрастается, `context-mgr` сжимает её в дайджест (Sonnet), раскладывает факты по темам в Obsidian-граф (`~/obsidian/`), а при переполнении делает hard-reset с сохранением памяти через невидимое system-message. Claude читает vault как тематическую память.

**Где:** код `tools/context-mgr/`, ставится per-user скриптом `setup/provision-user.sh`. Подробно — [docs/V2-MULTIUSER.md](docs/V2-MULTIUSER.md).

## 🔧 helpers — Полезные мелочи

**Что даёт:** набор небольших инструментов которые часто пригождаются:

| Инструмент | Что делает | Нужен ключ? |
|---|---|---|
| **openpyxl_safe** | Патч для Python библиотеки openpyxl — лечит баг с XLSX-файлами которые Excel не открывает корректно. Если работаете с генерацией Excel — обязательно. | Нет |
| **tg-md** | Конвертер MarkdownV2 для Telegram (правильно экранирует спецсимволы) | Нет |
| **nanobanana** | Генерация изображений через Gemini (бесплатно, лучше DALL-E для многих задач) | Да: Gemini API key |
| **gemini-tts** | Озвучка текста через Gemini TTS (отвечать голосом в TG) | Да: тот же Gemini API key |

**Что произойдёт при установке:**
- Все 4 инструмента скопируются в `/opt/`
- Спросит **только для тех что требуют ключ**: если хотите nanobanana и gemini-tts, попросит Gemini API key (бесплатно на https://aistudio.google.com/apikey)
- Те что без ключей — установятся в любом случае

**Установка:**
```bash
sudo bash install.sh --module helpers
# Или только без-ключей:
sudo bash install.sh --module helpers --skip-gemini
```

## 🎨 hooks-extras — Дополнительные хуки

**Что даёт:** автоматические правила поведения Claude. Например:
- После каждого изменения файла — запускать линтер
- Перед удалением — спрашивать подтверждение
- При работе в проекте X — подгружать его контекст автоматически
- Логировать все команды для аудита

**Когда нужно:** если хотите тонко настроить поведение Claude под свой стиль работы.

**Что вам нужно подготовить:**
- Ничего

**Что произойдёт при установке:**
- В `~/.claude/hooks/` добавятся примеры хуков
- Создастся конфиг где галочками включаете нужные
- Можно редактировать и писать свои

**Установка:**
```bash
sudo bash install.sh --module hooks-extras
```

## Сводная таблица: что когда нужно

| Сценарий | Минимальный набор модулей |
|---|---|
| **Просто попробовать Claude на сервере** | только core (никаких модулей) |

## Порядок установки модулей

Можно ставить в любом порядке. Но **рекомендуемый**:

1. **backup** — первым, чтобы все последующие установки сразу попадали под защиту бэкапов
2. **tg-bot** — чтобы получать уведомления от других модулей (память context-mgr подтянется сама)
3. **helpers** — по необходимости
4. **parakeet** — если планируете голосовое использование
5. **hooks-extras** — тонкая настройка в конце, когда поняли как пользуетесь

## Что если модуль перестал быть нужен

```bash
sudo bash uninstall.sh --module ИМЯ
```

Скрипт:
- Остановит и удалит systemd-юнит
- Удалит код из `/opt/` (если там был)
- Сохранит env-файлы в `~/.removed-modules-backup/` (на случай если передумаете)
- Не тронет данные (бэкапы на Я.Диске останутся, Obsidian-vault останется, и т.д.)
