# Установка Claude Code на сервер — пошагово

> Эта инструкция для тех кому уже **передали данные сервера** (IP, логин, пароль).
> Если не передали — попроси у того кто этим занимается.

---

## Что должно быть у тебя на руках

| Что | Получил откуда | Запиши сюда |
|---|---|---|
| **IP-адрес сервера** | Передал Сергей | `____ . ____ . ____ . ____` |
| **Логин** | Обычно `root` | `root` |
| **Пароль** | Передал Сергей (секретно) | `___________________` |

Запиши их в надёжное место (менеджер паролей **Bitwarden** / **1Password**, или защищённую заметку). Скоро понадобятся.

---

## Что мы сделаем

```
1. Установим VS Code на твой компьютер           (5 мин)
2. Установим расширение Remote-SSH               (1 мин)
3. Добавим сервер в конфиг                       (2 мин)
4. Подключимся к серверу                         (2 мин)
5. Установим расширение Claude Code              (3 мин)
6. Авторизуемся в Claude через расширение        (3 мин)
7. Установим серверную обвязку (наш kit)         (15 мин, ничего не нажимай)
8. Готово — пользуйся
```

---

## Шаг 1. Установи VS Code (5 минут)

Если уже установлен — пропусти. Если нет:

1. Открой в браузере: **https://code.visualstudio.com/download**
2. Скачай версию для своей системы:
   - **Windows** — синяя большая кнопка
   - **Mac** — выбери Intel или Apple Silicon (Apple Silicon для всех Mac с 2020 года и новее)
   - **Linux** — `.deb` для Ubuntu/Debian, `.rpm` для Fedora
3. Запусти установщик, согласись со всем по умолчанию.
4. Открой VS Code. На приветственном экране можно ничего не нажимать.

---

## Шаг 2. Установи расширение Remote - SSH (1 минута)

Это плагин для VS Code, который позволит подключаться к серверу.

1. В VS Code слева в боковой панели четыре квадратика (один отделён) — это **Extensions**. Или нажми:
   - **Windows / Linux:** `Ctrl + Shift + X`
   - **Mac:** `Cmd + Shift + X`
2. Сверху в строке поиска напечатай: **`Remote - SSH`**
3. Первый результат (автор **Microsoft**) — нажми кнопку **Install**.
4. Ничего перезагружать не надо.

После установки слева внизу VS Code появится **зелёная иконка** `><`.

---

## Шаг 3. Добавь сервер в конфигурацию (2 минуты)

1. В VS Code открой **Command Palette**:
   - **Windows / Linux:** `Ctrl + Shift + P`
   - **Mac:** `Cmd + Shift + P`
2. В строке вверху напечатай: **`Remote-SSH: Open SSH Configuration File`**
3. Выбери первый файл (обычно `Users/ТВОЁ_ИМЯ/.ssh/config` на Win/Mac, `/home/ТВОЁ_ИМЯ/.ssh/config` на Linux).
4. Откроется текстовый файл. Добавь в **самый конец** такие строки:

```
Host my-claude-server
    HostName ВПИШИ_СЮДА_IP
    User root
    Port 22
```

Замени `ВПИШИ_СЮДА_IP` на IP-адрес, который тебе передали. Например:
```
Host my-claude-server
    HostName 185.123.45.67
    User root
    Port 22
```

5. Сохрани файл: `Ctrl/Cmd + S`.
6. Закрой эту вкладку.

---

## Шаг 4. Подключись к серверу (2 минуты)

1. Слева внизу VS Code — **зелёная иконка** `><`. Кликни её.
2. В появившемся меню сверху выбери: **`Connect to Host...`**
3. Выбери **`my-claude-server`** (тот что только что добавили).
4. Откроется новое окно VS Code. Сверху появится строка с вопросом про тип системы. Выбери **Linux**.
5. Сверху появится поле для пароля. Введи **пароль с сервера** (символы будут скрыты или вообще не отображаться — это нормально). Нажми Enter.
6. Жди 1-2 минуты пока VS Code сам себя установит на сервере.

✅ Когда увидишь слева внизу **«SSH: my-claude-server»** зелёным — ты подключён.

> 💡 **Важно:** дальнейшие шаги делай **в этом новом окне** (подключённом к серверу), не в исходном.

---

## Шаг 5. Установи расширение Claude Code (3 минуты)

В том же VS Code-окне, которое подключено к серверу:

1. Открой **Extensions** (`Ctrl/Cmd + Shift + X`).
2. В поиске напечатай: **`Claude Code`**
3. Найди расширение от **Anthropic** (с фиолетовой звёздочкой / логотипом Anthropic). Это официальное.
4. Нажми **Install**.

Расширение поставится **сразу и на твоём компьютере, и на сервере** (в правом нижнем углу мелькнёт «Installing on SSH: my-claude-server» — это нормально, это нужно).

После установки слева в боковой панели появится **иконка Claude** (фиолетовая звёздочка или похожий значок Anthropic).

> 💡 Если расширение установилось только локально, не на сервере — открой Extensions ещё раз, найди Claude Code, и должна появиться кнопка **«Install in SSH: my-claude-server»**. Нажми её.

---

## Шаг 6. Авторизуйся в Claude через расширение (3 минуты)

1. Кликни на **иконку Claude** в левой боковой панели VS Code.
2. Откроется панель расширения. Внутри будет кнопка **«Sign in»** или **«Get Started»**.
3. Нажми её. Откроется браузер с страницей Anthropic.
4. Войди в свой аккаунт:
   - **Если у тебя есть подписка Claude Pro/Max/Team** ($20/мес и выше на https://claude.ai) — используй её. Авторизация через тот же email и пароль.
   - **Если нет подписки** — зарегистрируйся на **https://console.anthropic.com**, положи $5-10 на баланс (это для API).
5. Браузер попросит подтвердить, что VS Code может работать от твоего имени → подтверди.
6. Браузер скажет «You can close this tab» → закрой вкладку, вернись в VS Code.

✅ В панели Claude увидишь приветствие. **Можешь уже задать первый вопрос**, чтобы убедиться что работает:

```
Привет! Покажи, какие на этом сервере доступны skills и agents.
```

(На пустом сервере Claude ответит «их пока нет» — это нормально, мы их поставим на следующем шаге.)

---

## Шаг 7. Установи серверную обвязку — наш kit (15 минут)

Этот шаг ставит на сервер дополнительное: библиотеку готовых агентов и скиллов (~150 штук), систему модулей (Telegram-бот, бэкап, и т.д.), и базовую конфигурацию.

1. В том же VS Code-окне (подключённом к серверу) открой терминал:
   - В меню вверху: **Terminal → New Terminal**
   - Или нажми: <code>Ctrl + `</code> (обратная кавычка под Esc)
2. Внизу откроется чёрное окно. Увидишь приглашение типа `root@server:~#`.
3. **Скопируй эту команду полностью** и вставь в терминал (правая кнопка мыши → Paste, или `Ctrl+Shift+V` на Win/Linux, `Cmd+V` на Mac), затем нажми Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/SergeyLikholat/claude-code-server-kit/main/quickstart.sh | sudo bash
```

4. Скрипт начнёт работу. Будет показывать что делает.
5. **Когда задаст первый вопрос** «Готовы продолжить?» — напечатай `y` и Enter.
6. Дальше:
   - Будет ставить системные компоненты (~5 минут, без вопросов)
   - Если увидит что Claude Code CLI уже установлен расширением — пропустит
   - Скачает готовых агентов и скиллов (~3 минуты)
   - **Спросит про SSH-ключи** — если не разбираешься, ответь **`n`** (можно настроить позже)
   - **Спросит про модули** — отвечай как захочешь (см. таблицу ниже)

### Модули — что отвечать `y` или `n`

| Модуль | Когда `y` | Когда `n` |
|---|---|---|
| `claude-mem` | Хочешь чтобы Claude помнил прошлые разговоры | Не важно — можно потом |
| `helpers` | Хочешь полезные мелочи (генератор картинок, и т.п.) | Если нет API-ключа Gemini |
| `tg-bot` | Хочешь управлять Claude из Telegram | Если ещё не создал бота |
| `backup` | Хочешь ежедневный бэкап | Если нет OAuth-приложения в Яндексе |
| `parakeet` | Хочешь голосовые в TG | Только если ставишь `tg-bot` |
| `hooks-extras` | Если знаешь что это | Иначе нет |

**Если сомневаешься — отвечай `n` на всё.** Главное уже работает. Любой модуль добавляется позже одной командой (см. ниже).

---

## Шаг 8. Готово ✓

Открой панель Claude (иконка слева). Напиши:
```
Покажи теперь какие у меня агенты и скиллы.
```

Должен показать большой список (~150 штук). Это значит всё установилось правильно.

**Дальше — просто пользуйся.** Можно писать задачи в панели Claude, открывать с ним файлы на сервере, и т.д.

## Полезные дальнейшие шаги

### Добавить модули позже

Если на Шаге 7 ответил `n` на какие-то модули — добавь когда захочешь.

В терминале сервера:
```bash
# Какие модули вообще есть
sudo bash /root/claude-code-server-kit/install.sh --list

# Установить конкретный
sudo bash /root/claude-code-server-kit/install.sh --module backup
sudo bash /root/claude-code-server-kit/install.sh --module tg-bot
```

Подробности по каждому модулю — в файле **[MODULES.md](MODULES.md)** репозитория.

### Если хочешь подключаться без пароля (безопаснее)

После того как всё работает, можно настроить SSH-ключи и убрать пароль.

В терминале на сервере:
```bash
sudo bash /root/claude-code-server-kit/preflight-ssh.sh
```

⚠️ **Сначала прочитай** [docs/SSH-SETUP.md](docs/SSH-SETUP.md) — там как сгенерировать ключ на твоей системе (Win / Mac / Linux). Если запустить preflight без ключа — потеряешь доступ к серверу.

### Если что-то пошло не так

В первую очередь — **скопируй что написано в красном/жёлтом** и спроси у Сергея.

Если хочешь сам разобраться — [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

## Где это всё лежит на сервере

После установки на сервере появилось:

```
/root/claude-code-server-kit/   ← сам kit
/root/.claude/                   ← настройки твоего Claude Code (агенты, скиллы, правила)
/root/.claude-mem/               ← память Claude (если установил модуль)
/root/.secrets/                  ← ключи и пароли (chmod 600, не показывай!)
/opt/                            ← код установленных модулей (бот, бэкап, и т.п.)
```

Чтобы что-то поменять — редактируй файлы прямо в VS Code (он же подключён к серверу).
