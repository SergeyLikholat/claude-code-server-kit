# 🚀 QUICKSTART — установка с нуля за 30 минут

Эта инструкция для человека у которого:
- ✅ Есть **локальный компьютер** (Windows/Mac/Linux) с **VS Code** и плагином **Claude Code**
- ❌ **Нет сервера** или есть, но «чистый»
- 🎯 **Хочет** получить полностью настроенную серверную сборку Claude Code

После этой инструкции у вас будет:
- Свой сервер 24/7 с Claude Code
- Безопасный вход по SSH-ключам
- (опционально) Telegram-бот, бэкапы, транскрипция голоса, и т.д.

**Время:** 30–60 минут спокойно. **Деньги:** $5–10 в первый месяц. **Помощь автора не нужна.**

---

## Шаг 1 — Купить VPS (5 минут)

VPS = виртуальный сервер. Берите Ubuntu 24.04 LTS, минимум:
- 2 vCPU, 4 ГБ RAM, 50 ГБ SSD

Провайдеры:
- **Не РФ:** [Hetzner](https://hetzner.com) от €4/мес, [DigitalOcean](https://digitalocean.com), [Vultr](https://vultr.com)
- **РФ:** [Beget](https://beget.com), [Timeweb](https://timeweb.cloud), [Selectel](https://selectel.ru)

После покупки провайдер пришлёт email с:
- **IP-адресом** (например `185.123.45.67`)
- **Логином** (обычно `root`)
- **Паролем** для root

**Запишите эти три значения. Они нужны на Шаге 2.**

---

## Шаг 2 — Подключиться к серверу через VS Code (5 минут)

1. Откройте VS Code.
2. Слева внизу зелёная кнопка `><` → клик → выберите **«Connect to Host...»** → **«+ Add New SSH Host...»**
3. Введите: `ssh root@ВАШ_IP` (подставьте реальный IP с Шага 1) → Enter.
4. Выберите файл для сохранения SSH-конфига (любой из вариантов, обычно `~/.ssh/config`).
5. Снова `><` → **«Connect to Host...»** → выберите свой сервер.
6. Выберите тип системы → **Linux**.
7. Введите пароль от root (с email провайдера).
8. Ждите 1-2 минуты пока VS Code установится на сервере.

✅ В VS Code открыта вкладка с сервером. Внизу — терминал (`Терминал → Создать терминал`). Видите приглашение типа `root@your-server:~#` → **вы внутри сервера**.

---

## Шаг 3 — Запустить установщик одной командой (15 минут)

Скопируйте и вставьте в терминал сервера (внутри VS Code):

```bash
curl -fsSL https://raw.githubusercontent.com/SergeyLikholat/claude-code-server-kit/main/quickstart.sh | sudo bash
```

Скрипт автоматически:
1. ✅ Установит системные пакеты (git, docker, python, node)
2. ✅ Установит Claude Code CLI
3. ✅ Склонирует базу агентов и скиллов (~150 готовых)
4. ✅ Создаст базовый конфиг в `~/.claude/`
5. ❓ Спросит хотите ли настроить SSH-ключи (рекомендуется)
6. ❓ Спросит про опциональные модули (Telegram, бэкап, и т.д.)

**Никаких ключей API на этом этапе не нужно.** Минимум для запуска — нулевой.

---

## Шаг 4 — Авторизоваться в Claude (3 минуты)

После завершения установки в терминале сервера:

```bash
claude
```

Первый запуск откроет OAuth-ссылку. Скопируйте её, откройте в браузере вашего компьютера, войдите в Claude (или зарегистрируйтесь на https://console.anthropic.com — нужно положить $5-10 на баланс).

После авторизации:
```bash
claude
```
И вы в чате с Claude **прямо на своём сервере**. Можете писать ему задачи, он работает.

## Шаг 5 (опционально) — Добавить модули когда захотите

Скрипт quickstart.sh уже спросил про модули. Если хотите добавить позже:

```bash
cd /root/claude-code-server-kit

# Что вообще есть
sudo bash install.sh --list

# Установить конкретный модуль
sudo bash install.sh --module backup    # бэкап на Яндекс.Диск
sudo bash install.sh --module tg-bot    # Telegram-бот для управления с телефона
sudo bash install.sh --module parakeet  # транскрипция голосовых
sudo bash install.sh --module claude-mem # память между сессиями
sudo bash install.sh --module helpers   # nanobanana, gemini-tts, etc.
```

Для каждого модуля что нужно — описано в [MODULES.md](MODULES.md):
- **tg-bot:** создать бота через [@BotFather](https://t.me/BotFather), получить токен
- **backup:** создать OAuth-приложение в Яндексе (бесплатно, 2 минуты)
- **parakeet:** аккаунт на HuggingFace (бесплатно)
- **helpers с nanobanana/gemini-tts:** Gemini API key (бесплатно на https://aistudio.google.com/apikey)

Конкретные пошаговые инструкции для каждого модуля в `docs/`:
- [docs/TELEGRAM-SETUP.md](docs/TELEGRAM-SETUP.md)
- [docs/BACKUP-SETUP.md](docs/BACKUP-SETUP.md)

## Что важно сделать СЕЙЧАС (5 минут)

1. **Сохраните в менеджер паролей** (Bitwarden / 1Password):
   - IP-адрес сервера
   - Логин root
   - SSH-ключ (приватный) — если выбрали хранить
   - **Restic-пароль** если установили модуль backup ⚠️ КРИТИЧНО
   - Yandex client_id+secret если установили модуль backup

2. **Распечатайте на бумаге** и положите в сейф:
   - Restic-пароль (если установили backup)

   Без него зашифрованный бэкап = непрочитаемая каша навсегда. Это последний рубеж защиты.
