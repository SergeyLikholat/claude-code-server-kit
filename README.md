# Claude Code Server Kit

**Готовая сборка инфраструктуры вокруг Claude Code для работы на собственном сервере.**

> 📖 [English version (translation welcome)](docs/README.en.md)

---

## ⚡ Самый быстрый старт — одна команда

Если у вас уже есть **сервер с Ubuntu 24.04** (root + SSH-доступ):

```bash
curl -fsSL https://raw.githubusercontent.com/SergeyLikholat/claude-code-server-kit/main/quickstart.sh | sudo bash
```

Эта одна команда установит Claude Code, базу из ~150 готовых агентов/скиллов, и предложит модули (Telegram-бот, бэкап, и т.д.). **API-ключи на старте не нужны.**

**Никогда не настраивали сервер?** → читайте полную инструкцию в **[QUICKSTART.md](QUICKSTART.md)** (от покупки VPS до работающего Claude).

---

## Что это и зачем

Claude Code от Anthropic — это AI-помощник, который умеет писать код, читать файлы, запускать команды, и в целом работать как живой ассистент-разработчик. Если установить его не на свой ноутбук, а на сервер в интернете — он становится доступен 24/7: с любого устройства, в любое время.

Этот набор — **готовая обвязка** для такого «серверного» Claude Code. Один скрипт ставит всё что нужно, чтобы:

- 🤖 **Управлять Claude из Telegram** — пишешь ему сообщение с телефона, он работает на сервере, отвечает обратно
- 🎙️ **Голосовые сообщения** — диктуешь, Claude транскрибирует и обрабатывает
- 💾 **Автоматические бэкапы** на Яндекс.Диск — ежедневно, со ста защитой шифрованием
- 🧠 **Память между сессиями** — Claude помнит контекст прошлых разговоров
- 🔧 **Готовые правила и агенты** — для качественного кода, ревью, безопасности

**Всё работает на вашем сервере.** Ничего не уходит в чужие облака (кроме самих запросов к Claude API, что неизбежно).

После установки у вас на сервере будет:

| **Богатая база агентов и правил** | Готовые помощники для код-ревью, тестов, безопасности и т.д. (~150 скиллов) |
| **Telegram-бот** *(опционально)* | Управление Claude с телефона: пишешь задачу в TG, Claude её делает |

## Что нужно чтобы начать

Минимум:
- 🖥️ **Сервер** — Ubuntu 24.04 (рекомендуется), доступ root + SSH
- 💳 **Учётка Anthropic** — для оплаты Claude (бесплатные лимиты есть, но скромные)
- 💻 **Ваш компьютер** — Windows / Mac / Linux, любой

Опционально (для соответствующих модулей):
- 📱 **Telegram-бот** — бесплатно создаётся за минуту через @BotFather
- 💾 **Яндекс.Диск** — бесплатные 5 ГБ хватает на бэкапы маленького сервера
- 🎤 **HuggingFace аккаунт** — бесплатно, для скачивания моделей транскрипции

**Никаких ключей при первой установке не требуется.** Core устанавливается без единого секрета. Модули добавляете когда захотите.

## Установка за 5 минут

### Шаг 1: Подключитесь к серверу

Обычно VPS-провайдер даёт вам **IP-адрес** и **пароль** для root. Подключитесь через SSH:

- **На Windows:** [пошаговая инструкция](docs/SSH-SETUP.md#windows)
- **На Mac:** [пошаговая инструкция](docs/SSH-SETUP.md#mac)
- **На Linux:** [пошаговая инструкция](docs/SSH-SETUP.md#linux)

### Шаг 2: Настройте SSH-ключи *(рекомендуется, для безопасности)*

Чтобы заходить на сервер без пароля и сделать его безопаснее:

```bash
curl -fsSL https://raw.githubusercontent.com/SergeyLikholat/claude-code-server-kit/main/preflight-ssh.sh | bash
```

Скрипт сам определит вашу ситуацию, спросит куда положить ключи и всё настроит. **Детали:** [SSH-SETUP.md](docs/SSH-SETUP.md).

### Шаг 3: Установите core (обязательная база)

```bash
git clone https://github.com/SergeyLikholat/claude-code-server-kit
cd claude-code-server-kit
sudo bash install.sh
```

Это поставит Claude Code, базовые правила и агентов. **Никаких ключей или регистраций не просит.** Через 3-5 минут у вас рабочий Claude Code.

### Шаг 4 (опционально): Добавьте модули когда захотите

Каждый модуль — отдельная команда. Хотите Telegram-бота:

```bash
sudo bash install.sh --module tg-bot
```

Скрипт интерактивно спросит что нужно (например, токен бота от @BotFather), сам всё настроит.

Все модули и что они дают — в [MODULES.md](MODULES.md).

### Шаг 5: Начните пользоваться

```bash
claude
```

Готово. Можно работать.

## Часто задаваемые вопросы

**А это безопасно?**
Да. Весь код открыт (можете прочитать любой скрипт перед запуском). Ваши данные остаются на вашем сервере. SSH-настройка из этого kit'а делает сервер **более** защищённым чем стандартный VPS «из коробки».

**Сколько это стоит?**
- Этот kit — **бесплатно** (MIT-лицензия)
- VPS — от $5/мес у любого провайдера
- Claude API — по тарифу Anthropic, зависит от вашей нагрузки (от $5/мес для лёгкого использования)
- Опциональные сервисы (Telegram, Яндекс.Диск, HuggingFace) — **бесплатно** в нужных нам объёмах

**Я не программист, справлюсь?**
Если умеете копировать команды и читать инструкции — да. Документация написана для обычных людей, не для админов. Если застрянете — открывайте [issue](https://github.com/SergeyLikholat/claude-code-server-kit/issues), помогу.

**Можно ли использовать без Telegram / без бэкапа / без X?**
Да, всё опционально. Core устанавливается отдельно, модули добавляются по желанию. Никаких обязательных интеграций.

**А если что-то сломается?**
Каждый модуль удаляется отдельно (`uninstall.sh --module <name>`). Core откатывается тоже. Бэкап (если поставили) защитит ваши данные. Логи всех операций сохраняются.
