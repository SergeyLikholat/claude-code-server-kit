# ~/.claude/commands/ — Slash-команды

Slash-команды (`/команда`) — это шаблоны промптов для повторяющихся задач.

После установки core доступны из коробки 88+ команд из ECC base. Свои добавляйте сюда:

```
# ~/.claude/commands/my-review.md
---
description: Моё код-ревью в стиле команды
---

Сделай code review последнего коммита по нашему чек-листу:
- Безопасность
- Производительность
- Стиль кода
- Тесты
```

После создания файла команда `/my-review` становится доступной.

Полная документация: https://docs.claude.com/en/docs/claude-code/slash-commands
