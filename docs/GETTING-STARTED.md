# Getting Started — от нуля до работающей сборки

> Эта инструкция для тех у кого пока **нет сервера и нет опыта**. От «я только что услышал про это» до «у меня работает свой Claude Code на сервере с Telegram-ботом» — за 1 вечер.

---

## Что вам нужно перед началом

✅ **Карточка для онлайн-оплаты** — для VPS и Claude API. От $10 в первый месяц на всё про всё хватит.

✅ **Email** — для регистрации в Anthropic.

✅ **Любой компьютер** с интернетом — Windows / Mac / Linux.

✅ **Час свободного времени** — на спокойную установку без спешки.

❌ Опыт системного администрирования **не нужен**. Если вы умеете копировать команды по инструкции — справитесь.

## Шаг 1: Купите VPS (виртуальный сервер)

VPS — это «компьютер в облаке» которым вы управляете удалённо. Стоит от $5/мес.

### Что выбрать

**Минимальная конфигурация:**
- 2 vCPU
- 4 ГБ RAM
- 50 ГБ SSD
- Ubuntu 24.04 LTS

**Если планируете полную сборку с TG-ботом, бэкапом, претендуете на серьёзную работу:**
- 4 vCPU
- 8-16 ГБ RAM
- 100-200 ГБ SSD

### Где купить

Для не-резидентов РФ:
- **[Hetzner](https://hetzner.com)** (Германия) — лучшее соотношение цена/качество, от €4/мес
- **[DigitalOcean](https://digitalocean.com)** (США) — простой интерфейс, от $6/мес
- **[Vultr](https://vultr.com)** — много регионов

Для резидентов РФ (если хотите оплату с российских карт):
- **[Beget](https://beget.com)** — VPS от 250₽/мес
- **[Timeweb](https://timeweb.cloud)** — от 200₽/мес
- **[Selectel](https://selectel.ru)** — больше для бизнеса

> 💡 **Совет:** если только пробуете — берите самую дешёвую конфигурацию. Можно потом «апгрейднуть» (увеличить ресурсы) одной кнопкой если станет мало.

### После покупки

Провайдер пришлёт email с:
- **IP-адресом** сервера (например `185.123.45.67`)
- **Логином** (обычно `root`)
- **Паролем** для root

Сохраните эти данные. Скоро пригодятся.

## Шаг 2: Установите программу для подключения к серверу

### Если у вас Windows

Установите **[VS Code](https://code.visualstudio.com/)** (бесплатно). Это удобный редактор + терминал в одном окне.

После установки добавьте плагин **«Remote - SSH»**:
1. Откройте VS Code
2. Слева кнопка с квадратиками (Extensions)
3. В поиске напечатайте: `Remote - SSH`
4. Нажмите Install у первого результата от Microsoft

### Если у вас Mac или Linux

VS Code + Remote-SSH работает так же как на Windows. Или можете пользоваться встроенным Terminal (Cmd+Пробел → Terminal на Mac, Ctrl+Alt+T на Linux).

## Шаг 3: Подключитесь к серверу первый раз (по паролю)

### Через VS Code (рекомендуется для новичков)

1. Откройте VS Code
2. Слева внизу зелёная кнопка `><` (Open a Remote Window)
3. Выберите `Connect to Host...` → `+ Add New SSH Host`
4. Введите: `ssh root@ВАШ_IP` (подставьте реальный IP)
5. Сохраните в `~/.ssh/config` (любой из вариантов)
6. Снова `><` → `Connect to Host...` → выберите свой сервер
7. Выберите тип системы → **Linux**
8. Введите пароль (тот что в email от провайдера)
9. Подождите пока VS Code установит свой `vscode-server` на ваш VPS (1-2 минуты)

Готово! Открыта вкладка с сервером. Откройте терминал внутри VS Code: `Терминал → Создать терминал`. Видите `root@your-server:~#` — вы внутри сервера.

### Через обычный терминал (если предпочитаете)

**Windows:** Win+R → `powershell` → Enter:
```powershell
ssh root@ВАШ_IP
```

**Mac/Linux:** откройте Terminal:
```bash
ssh root@ВАШ_IP
```

Спросит «yes/no» — `yes`, потом пароль. Внутри сервера.

## Шаг 4: Настройте безопасный вход по ключам

**Важно сделать сейчас**, до установки чего-либо ещё.

Полная инструкция: **[SSH-SETUP.md](SSH-SETUP.md)** (есть отдельные разделы для Windows / Mac / Linux).

Кратко: на **локальном** компьютере (не на сервере!) выполните:

```bash
ssh-keygen -t ed25519 -C "$(whoami)@$(hostname)"
ssh-copy-id root@ВАШ_IP
```

После этого подключайтесь без пароля. Это **намного безопаснее** и удобнее.

> ⚠️ Не делайте следующий шаг (preflight-ssh) пока не убедитесь что **без пароля заходит** — иначе можно случайно потерять доступ к серверу.

После проверки запустите на сервере:
```bash
curl -fsSL https://raw.githubusercontent.com/SergeyLikholat/cc-multiuser-kit/main/preflight-ssh.sh | bash
```

Это **отключит вход по паролю совсем** и сделает сервер устойчивым к перебору паролей.

## Шаг 5: Установите Core (базовая часть Claude Code Server Kit)

На сервере выполните:

```bash
cd /root
git clone https://github.com/SergeyLikholat/cc-multiuser-kit
cd claude-code-server-kit
sudo bash install.sh
```

Что произойдёт (всего ~5 минут):
1. Установятся системные пакеты (curl, git, python, node, и т.д.)
2. Установится Claude Code CLI
3. Склонируется база агентов и скиллов
4. Создастся базовый конфиг в `~/.claude/`
5. Покажется приветствие и инструкция «что дальше»

**Никаких ключей и паролей не спросит.** Это специально — чтобы можно было попробовать без вложений.

## Шаг 6: Зарегистрируйтесь в Claude и авторизуйтесь

1. Откройте https://console.anthropic.com/
2. Зарегистрируйтесь (email + код)
3. Закиньте $10 на баланс (или начните с бесплатной квоты)

На сервере:
```bash
claude
```

Первый запуск попросит авторизацию — следуйте инструкциям на экране (откроется OAuth в браузере).

После этого:
```bash
claude --help
```

Должны увидеть подсказки. Готово — Claude работает.

## Шаг 8 (по желанию): Добавьте модули

Теперь когда core работает, можете добавлять модули по одному.

**Самый ценный — backup.** Он защитит ваши данные:
```bash
sudo bash install.sh --module backup
```

Скрипт интерактивно проведёт через:
1. Создание OAuth-приложения в Яндексе (даст ссылку, объяснит)
2. Получение токена
3. Генерацию пароля шифрования (покажет один раз — обязательно сохраните!)
4. Тестовый бэкап
5. Включение ежедневного расписания

Подробно: **[BACKUP-SETUP.md](BACKUP-SETUP.md)**.

**Дальше — Telegram-бот** если хотите управление с телефона:
```bash
sudo bash install.sh --module tg-bot
```

Проведёт через создание бота, настройку группы. Подробно: **[TELEGRAM-SETUP.md](TELEGRAM-SETUP.md)**.

**Полный список модулей с описанием:** **[MODULES.md](../MODULES.md)**.

## Что важно помнить

### Безопасность

- ✅ **SSH-ключи настроены** (Шаг 4)
- ✅ **Вход по паролю отключён** (preflight-ssh.sh)
- ✅ **fail2ban стоит** (включается в preflight-ssh.sh, защищает от ботов)
- ✅ **Backup настроен** (рекомендуется как можно раньше)

### Регулярное обновление

Раз в месяц обновляйте систему и kit:
```bash
sudo apt update && sudo apt upgrade -y
cd /root/claude-code-server-kit
git pull
```

### Если что-то идёт не так

1. Смотрите [TROUBLESHOOTING.md](TROUBLESHOOTING.md)
2. Откройте [issue на GitHub](https://github.com/SergeyLikholat/cc-multiuser-kit/issues)
3. В крайнем случае — пересоздайте VPS (если backup настроен, восстановите из него; если нет — потеряете данные, не критично если только пробовали)
