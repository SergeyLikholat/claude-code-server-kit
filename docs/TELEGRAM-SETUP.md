# Настройка Telegram-бота

> Инструкция к модулю `tg-bot`. Цель — установить бота за 15-30 минут с нуля.

---

## Что вы получите

Личный Telegram-бот, через которого вы будете общаться со своим Claude Code на сервере:
- Пишете сообщение в TG → бот передаёт Claude → Claude отвечает в TG
- Можете отправлять текст, голосовые, фото, файлы
- Поддерживается «форум-группа» с топиками — разные проекты в разных топиках
- Уведомления от других модулей (бэкап, мониторинг) приходят сюда же

---

## Шаг 1: Создайте бота через BotFather

1. Откройте Telegram, найдите **[@BotFather](https://t.me/BotFather)** (официальный бот Telegram)
2. Напишите ему: `/newbot`
3. Придумайте **отображаемое имя** (любое, например «Мой Claude»)
4. Придумайте **username** — должен заканчиваться на `_bot`, быть уникальным:
   - Например `IvanovClaudeAssistant_bot`
   - Если занято — попробуйте другой
5. BotFather пришлёт **токен** вида:
   ```
   123456789:ABCdef1234ghIklZyxWvuT5g4FjHsm6E7N
   ```
   Это **секрет** — никому не показывайте.

### Полезные настройки бота (опционально)

В чате с BotFather:
- `/setdescription` → описание которое видят пользователи
- `/setuserpic` → аватарка
- `/setcommands` → подсказки команд (например `/help`)

### Важно — отключите Privacy Mode для работы в группах

По умолчанию бот в группах видит **только** сообщения адресованные ему (`@bot_name ...` или ответ на его сообщение). Для удобства можно разрешить ему видеть все:

```
/mybots → выберите бота → Bot Settings → Group Privacy → Turn off
```

⚠️ Это значит бот будет «слышать» все сообщения в группах куда его добавили. Делайте только если бот в **личных** группах (не публичных).

## Шаг 2: Создайте группу для общения

Можно использовать существующую группу или создать новую.

### Вариант A: Обычная группа (просто)

1. В TG: создать группу → добавить **только себя и бота**
2. Назовите как-нибудь: «Claude», «AI Assistant», что хотите

### Вариант B: Форум-группа (рекомендуется для нескольких проектов)

Форум-режим даёт «топики» внутри группы — это как папки. У вас может быть топик «Работа», «Личное», «Бэкап-уведомления» и т.д.

1. Создайте обычную группу
2. Сделайте её супергруппой: добавьте >5 человек (можно своих ботов) или включите историю для новых участников
3. В настройках группы → **Topics → On**
4. Создайте топики (правый верх → New topic)

---

## Шаг 3: Узнайте chat_id вашей группы

Это число вида `-1001234567890` (для супергрупп начинается с `-100`). Нужно чтобы бот знал куда писать.

### Самый простой способ

1. Добавьте в группу бота **[@username_to_id_bot](https://t.me/username_to_id_bot)** (или любого аналогичного)
2. Он покажет ID группы
3. Удалите бота из группы

### Через ваш собственный бот (после установки)

Если уже установили модуль, в логах сервера:
```bash
journalctl -u tg-router -f
```
Напишите любое сообщение в группу → в логах увидите `chat.id: -100...`.

## Шаг 4: Запустите установку модуля

На сервере, в директории kit'а:

```bash
sudo bash install.sh --module tg-bot
```

Скрипт спросит:

```
Telegram Bot Token (от @BotFather):
> 123456789:ABCdef...

Telegram Chat ID (группа куда бот пишет, например -1001234567890):
> -1001234567890

Использовать форум-режим с топиками? [y/N]:
> y

Если форум — введите thread_id топика "general" (по умолчанию 1):
> 1
```

Скрипт:
- Скопирует код бота в `/opt/claude-telegram-router/`
- Сохранит токен в `/root/.claude/channels/telegram/.env` (chmod 600)
- Создаст systemd-юнит `tg-router.service` с `Restart=always`
- **Включит автозапуск (`systemctl enable`)** — после перезагрузки сервера бот сам запустится
- Запустит и проверит что бот отвечает

### Автозапуск после перезагрузки

`tg-router.service` устанавливается **enabled** — это значит:
- После `reboot` сервера бот запустится автоматически
- Если бот упал (ошибка / OOM) — systemd рестартует через 5 секунд (`Restart=always`)
- Проверить что enabled: `systemctl is-enabled tg-router` → должно быть `enabled`
- Логи перезапусков: `journalctl -u tg-router -n 100`

### Второй бот (опционально)

Если нужен **второй бот** на том же сервере (например, для семьи / команды / разделения личного и рабочего):

```bash
sudo bash install.sh --module tg-bot -- --second-bot
```

Установит отдельный systemd-юнит `tg-router2.service` с независимым:
- Кодом в `/opt/claude-telegram-router2/`
- Конфигом в `/root/.claude/channels/telegram2/.env`
- Lock-директорией `/run/claude-telegram2/`
- Также `enabled` (автозапуск)

Боты работают параллельно, не конфликтуют.

## Шаг 5: Проверка работы

В группе напишите:
```
Привет!
```

Бот должен через 5-10 секунд переслать ваше сообщение в Claude, а ответ Claude — обратно в группу.

Если что-то пошло не так — см. [Troubleshooting](#troubleshooting) ниже.

## Как пользоваться

### Простое сообщение

Просто пишите боту/в группу что хотите чтобы Claude сделал:
```
Прочитай файл /root/notes/idea.md и подскажи как развить идею
```

Бот передаст в Claude, ответ придёт в TG.

### Голосовое сообщение

Если установлен модуль `parakeet`:
1. Запишите голосовое в TG (зажмите микрофон)
2. Бот скачает, расшифрует, передаст текст в Claude
3. Claude ответит

Без `parakeet` бот пришлёт «голосовая транскрипция не настроена».

### Фото

Прикрепите фото к сообщению:
```
Что на этой картинке? Опиши подробно.
```
(Claude умеет работать с изображениями, бот пересылает их в чат)

### Файлы

Прикрепите PDF/TXT/DOCX/что угодно:
```
Прочитай этот файл и сделай summary
```

### Команды для бота

В чате с ботом (или в группе):
- `/help` — справка
- `/clear` — начать новую сессию (забыть контекст)
- `/status` — статус Claude и серверной части

## Использование топиков (если форум-режим)

Если включили форум, можете создать топики под проекты:
- **Топик «Личное»** — личные задачи, идеи
- **Топик «Работа: Проект А»** — кодинг по проекту А, Claude подгружает контекст проекта
- **Топик «Бэкап»** — сюда приходят уведомления о бэкапах
- **Топик «Мониторинг»** — алерты от других сервисов

Чтобы Claude автоматически подгружал контекст проекта в зависимости от топика — настройте маршрутизацию в `~/.claude/scripts/telegram-routing.json`:

```json
{
  "by_thread_id": {
    "10": "/root/projects/project-a/CLAUDE.md",
    "20": "/root/projects/project-b/CLAUDE.md"
  }
}
```

(Где `10`, `20` — `message_thread_id` соответствующих топиков, узнать через debug-режим бота.)

## Конфиденциальность

- **Все сообщения проходят через серверы Telegram** — Telegram их видит. Не пишите боту что-то что не написали бы в обычной TG-переписке.
- **Содержимое отправляется в Anthropic Claude API** — то же что и при использовании веб-чата Claude. См. [политику Anthropic](https://www.anthropic.com/legal/aup).
- **Бэкап сообщений** — бот сам ничего не сохраняет долгосрочно (только короткий буфер для контекста сессии). Если хотите долгосрочную память — установите модуль `claude-mem`.
- **Список чатов где может работать бот** — ограничен `~/.secrets/tg-bot.env` параметром `TELEGRAM_ALLOWED_CHATS`. По умолчанию — только тот chat_id что вы указали при установке. Никто кроме вас не может «открыть бота».

## Troubleshooting

### Бот не отвечает

```bash
# Проверить что сервис запущен
systemctl status tg-router

# Посмотреть логи
journalctl -u tg-router -n 50

# Перезапустить
sudo systemctl restart tg-router
```

### «Conflict: terminated by other getUpdates request»

Значит ещё кто-то запустил поллинг с тем же токеном (например, бот раньше работал на другом сервере, или есть VSCode-вкладка с тем же ботом).

```bash
# Остановите всё
sudo systemctl stop tg-router

# Очистите webhook (на всякий случай)
curl -X POST "https://api.telegram.org/bot$TOKEN/deleteWebhook?drop_pending_updates=true"

# Запустите снова
sudo systemctl start tg-router
```

### Бот видит свои же сообщения и зацикливается

Бывает если включили в `BotFather` privacy off и бот реагирует на свои сообщения. В `/opt/claude-telegram-router/access.js` есть фильтр `ignore_bot_messages: true` — убедитесь что включён.

### «Я хочу разрешить ботом пользоваться кому-то ещё»

В `/root/.secrets/tg-bot.env`:
```bash
TELEGRAM_ALLOWED_CHATS=-1001234567890,-1009876543210
TELEGRAM_ALLOWED_USERS=123456789,987654321
```
И перезапустите: `sudo systemctl restart tg-router`.

⚠️ Бот получит доступ к вашему серверу через Claude. Доверяйте только тем кто имеет право на полный доступ.

### Хочу другой стиль — без бота, через webhook

См. [ADAPT.md](ADAPT.md) → раздел про кастомизацию модулей.

## Удаление модуля

```bash
sudo bash uninstall.sh --module tg-bot
```

- Остановит и удалит сервисы
- Удалит код из `/opt/claude-telegram-router/`
- Сохранит `~/.secrets/tg-bot.env` в `~/.removed-modules-backup/` (на случай если передумаете)
- НЕ удаляет самого бота в Telegram — это делайте сами через @BotFather (`/deletebot`)
