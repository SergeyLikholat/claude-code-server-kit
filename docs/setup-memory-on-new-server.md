# Промпт для Claude Code на новом сервере

> Скопируй всё, что ниже разделителя, в новую сессию Claude Code на том сервере.

---

## Задача: поставить систему долговременной памяти

Нужно установить и настроить систему накопительной памяти для Claude Code. Она собирает
знания из моих сессий и подставляет их в контекст автоматически, чтобы ты помнил, о чём
мы говорили неделю назад.

**Репозиторий:** https://github.com/SergeyLikholat/llm-memory-kit

Прочитай там `README.md`, `docs/how-it-works.md` и `docs/customize.md` — в них вся механика.
Ниже — только то, что специфично для моей установки и чего в документации нет.

## Как это работает в двух словах

Ночью по расписанию:
1. `digest` читает транскрипты моих сессий (`~/.claude/projects/*/*.jsonl`)
2. `classify` раскладывает их по проектам
3. `builder` превращает активность в накопительные темы-карточки
4. хук на каждый мой запрос находит релевантные темы и подставляет **сами факты** в контекст

Всё работает на моей подписке Claude (headless-вызовы `claude -p`), API-ключи не нужны.

## ВАЖНО: моя специфика — Obsidian создаётся с нуля

В ките есть Obsidian-модуль. Он состоит из двух независимых частей, и мне нужна **только одна**:

| Часть | Что делает | Нужна мне? |
|---|---|---|
| `obsidian-wiki-sync.js` | синхронизирует **существующие** заметки в карты (MOC) | ❌ нет — заметок у меня нет |
| `mirror-to-vault.js` | **витрина памяти**: зеркалит темы + строит дашборд здоровья | ✅ да, ради этого всё |

**У меня нет базы заметок в Obsidian и я не веду их.** Obsidian-волт нужен исключительно
как удобная витрина: смотреть структуру памяти, её рост, граф связей и следить, что система
не сломалась. Поэтому:

- при установке **укажи путь к новой, пустой папке** — например `~/Vault` или `~/memory-vault`;
- создавать её заранее и класть туда что-либо **не нужно** — `mirror-to-vault.js` сам создаст
  внутри `_wiki/память/` со всей структурой и дашбордом;
- `obsidian-wiki-sync.js` на волте без git корректно выходит с сообщением «волт не под git —
  пропуск» и ничего не ломает. Отключать его специально не требуется. Если однажды я начну
  вести заметки — сделаю `git init` в волте, и он заработает сам.

## Порядок действий

1. **Клонируй и запусти установщик:**
   ```bash
   git clone https://github.com/SergeyLikholat/llm-memory-kit.git
   cd llm-memory-kit && ./install.sh
   ```

2. **Ответы установщику:**
   - папка Claude Code, папка проектов, бинарь `claude` — оставь дефолты, если они верны;
   - модель для ночных вызовов — `sonnet` (заметно экономнее opus, качества хватает);
   - **Obsidian-sync → ДА**, путь — новая пустая папка (см. раздел выше);
   - маппинг доменов волта — **пропусти всё** (Enter на каждый вопрос): доменов нет, заметок нет;
   - приватные проекты — если есть темы, которые не должны всплывать в подсказках, перечисли;
   - создание первого проекта — на твоё усмотрение.

3. **Пропиши хуки.** Установщик в конце напечатает JSON для `~/.claude/settings.json` —
   добавь его в секцию `"hooks"`. Без этого память будет копиться, но не подставляться
   в контекст. Это самый частый пропущенный шаг.

4. **Проверь, что цепочка работает** (не жди ночи):
   ```bash
   node core/digest.js                # собрать сырьё из моих сессий
   ./core/memory-cron.sh              # построить темы (займёт несколько минут)
   node obsidian/mirror-to-vault.js   # собрать витрину и дашборд
   ```
   Затем открой `<волт>/_wiki/память/память-дашборд.md` — там должно быть видно контуры
   и число тем. Раздел «база знаний» покажет нули: заметок нет, это нормально.

5. **Сквозной тест** — главная проверка. Задай хуку вопрос про то, что реально обсуждалось
   в моих недавних сессиях:
   ```bash
   echo '{"prompt":"<вопрос по недавней теме>"}' | node hooks/memory-retrieval.js
   ```
   Должен вернуться блок с релевантными темами и цитатами из них. Если пусто — память
   собралась, но извлечение не работает: проверь пути в `config.sh` и хуки в `settings.json`.

## На что обратить внимание

**Если сервером пользуюсь не только я.** В ките есть граница личных контуров: сессии других
людей (их проекты в `$HOME/projects_other/`) не попадают в мою память, у каждого строится
своя через `core/other-memory-cron.sh`. Если на сервере есть чужие контуры — убедись, что
это настроено, и проверь, что в моих темах не появляется чужого. Подробности —
в `docs/customize.md`, раздел про несколько человек.

**Темы я не завожу руками.** Система создаёт их сама из моих сессий. Не надо размечать
категории заранее — просто работаем как обычно, карточки появятся после первого прогона.

**Расписание.** Основной прогон ночью + окна днём на случай исчерпанных лимитов подписки.
Частых ретраев намеренно нет: обёртки держат гард (3 попытки в сутки), иначе прогон
сжигает лимит. Не увеличивай частоту.
